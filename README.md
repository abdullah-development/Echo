# Live Reply Agent

Listens to your Mac's system audio (YouTube, Google Meet, Zoom, podcasts…), transcribes it
locally, notices when someone asks a question, and drafts a natural, human-sounding reply,
grounded in your own supporting documents, in a live panel at http://localhost:8766.

```
system audio ──► bin/audiotap (Swift, ScreenCaptureKit, 16 kHz PCM)
             ──► segmenter (splits on pauses)
             ──► Whisper (local, faster-whisper)
             ──► question detector ──► claude -p + docs/ + profile.md ──► live panel
```

## Setup

Replies are generated by your locally installed **Claude Code** (`claude -p`), using whatever
account you're signed in with, so there's no API key to configure. Make sure `claude` works in your terminal.

```sh
cp .env.example .env      # optional: set MY_NAME, mode, model
./run.sh                  # builds the audio helper on first run, then open http://localhost:8766
```

On first launch macOS asks for **Screen & System Audio Recording** permission for your terminal
(System Settings → Privacy & Security). Grant it, then restart the terminal and `./run.sh`.
The first run also downloads the Whisper model (~150 MB for `base.en`).

## Versions

| Command | What runs |
|---|---|
| `./run.sh v1` (default) | **Version 1**: quick transcript only (`base.en`). Fastest, least accurate. Code in `agent_v1/` (frozen). |
| `./run.sh v2` | **Version 2, hybrid**: the quick transcript appears instantly (grey) and replies start right away; `large-v3-turbo` re-transcribes each clip ~8 s later and corrects the line. If the correction changes a real word of an answered question, the answer is rewritten in place (tagged *updated*). Replies also start ~1.5 s sooner: a Claude Code process is kept booted and waiting. Code in `agent/`. |

| `./run.sh v3` | **Version 3, Parakeet**: NVIDIA Parakeet TDT 0.6B v3 (int8, CPU) instead of Whisper: 3.3% word errors vs 11.2% for `base.en` and 5.3% for turbo, at ~0.3 s per question. Misheard names from your docs are fixed by sound (`Cuban eats` → Kubernetes). Fast replies as in v1. Model files go in `models/parakeet-tdt-0.6b-v3-int8/` (from huggingface.co/istupakov/parakeet-tdt-0.6b-v3-onnx: `*.int8.onnx`, `nemo128.onnx`, `vocab.txt`, `config.json`). Code in `agent_v3/`. |

The first `v2` run downloads the turbo model (~1.6 GB).

## Make it answer as you

- **`profile.md`** (copy `profile.example.md` to start): who you are, your role, how you like to sound.
- **`docs/`**: drop in `.md`, `.txt`, `.csv` or `.pdf` files (resume, project status, product
  notes, pricing, agenda…). Click **Reload docs** after changing them.

## Using the panel

| Control | What it does |
|---|---|
| **Meeting / Video** | Meeting: writes what *you* should say back. Video: answers questions asked in the video. |
| **Auto: questions** | Drafts a reply when a question is detected (or your name is said). |
| **Every line** | Lets Claude judge every utterance (more Claude calls, catches implicit questions). |
| **Manual** | Only replies when you press **Answer now** (or the `A` key). |
| **Ask box** | Type any question to answer from your docs. |

## Testing without live audio

```sh
say -o /tmp/q.aiff "Sarah, when will the mobile release be ready for testing?"
MY_NAME=Sarah ./run.sh v2 --simulate /tmp/q.aiff
```

## Tuning (`.env`)

- `WHISPER_MODEL`: `tiny.en` is fastest, `small.en` is more accurate. Use `base`/`small` (no `.en`) for other languages.
- `CLAUDE_MODEL`: empty uses your Claude Code default; `sonnet`/`haiku` reply faster.
- `CLAUDE_EFFORT`: `low` gives the fastest replies; `medium`/`high` give more careful ones.
- Your own microphone is not captured; only what others say comes through system audio.

> Recording or transcribing other people can require their consent depending on where you are.
> Audio is transcribed locally; only the text transcript (plus your docs) is sent to Claude via Claude Code.
